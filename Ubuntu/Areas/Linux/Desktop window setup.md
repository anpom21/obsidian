## Switching desktop on all monitors

**Settings → Multitasking → Multi-Monitor → Workspaces on primary display only**.

## Tilling windows
Install the Extension Manager:
```
sudo apt install gnome-shell-extension-manager
```
Then:

1. Open **Extension Manager**.
2. Select **Browse**.
3. Search for **Tiling Shell**.
4. Install and enable it.
5. Open its settings and use the layout editor.
